# Portfolio

Portfólio pessoal de Rafael Silva, engenheiro de software Back-End especializado em Java e Spring Boot.

## Sobre

Esse projeto é um site estático que apresenta:
- Apresentação profissional
- Serviços e modo de trabalho
- Projetos autorais com links para repositórios
- Contato e redes sociais

## Tecnologias

- HTML
- CSS
- SVG

## Conteúdo

- `index.html`: página principal do portfólio
- `style.css`: estilos e temas do layout
- `favicon.svg`: favicon do site

## Execução local

Basta abrir `index.html` no navegador ou servir a pasta em um servidor HTTP simples.

Exemplo com Python:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.
